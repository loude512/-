# 末日横板：枪械与棍棒打丧尸

一个纯前端、零依赖的 2D 横板网页小游戏。玩家在末日街区中上下左右自由走位，用 **球棍** 近身横扫，或切换 **手枪** 风筝尸潮。

## 一键开始

### Windows
双击 `start.bat`，或执行：

```bash
npm start
```

### macOS / Linux
```bash
npm start
```

也可以直接运行：

```bash
node server.js
```

启动后服务器会打印入口网址，例如：

```
本机网址:   http://127.0.0.1:5173
局域网网址: http://192.168.x.x:5173
```

- 自己玩：打开 `http://127.0.0.1:5173`
- 局域网朋友玩：让手机/电脑与服务器连接同一 Wi-Fi，输入服务器打印的局域网网址。
- 自定义端口：

```bash
node server.js --port=8080
# 或
PORT=8080 node server.js
```

服务器还提供健康检查接口：

```
http://127.0.0.1:5173/healthz
```

## 让互联网上的玩家访问

本仓库本身是零依赖静态游戏，可以直接托管到任意静态平台。最简单的方式：

```bash
# 以 Vercel 为例，需要提前安装并登录 Vercel CLI
npx vercel --prod

# 或以 Netlify 为例
npx netlify deploy --prod --dir .
```

部署完成后会得到一个固定公网网址，其他玩家输入网址即可游玩。

如果不部署公网服务，也可以使用内网穿透工具，把本地 `http://127.0.0.1:5173` 映射到公网。

## 操作说明

### 电脑端

| 操作 | 按键 |
| --- | --- |
| 上 / 下 / 左 / 右移动 | `W` `A` `S` `D` 或方向键 |
| 攻击（瞄准 / 挥棍 / 射击） | 鼠标左键、`J`、`空格` |
| 切换武器 | `Q`、页面“切换武器”按钮 |
| 直接选择武器 | `1` = 球棍，`2` = 手枪 |
| 子弹耗尽 | 自动切换球棍；拾取弹药后自动切回手枪，也可随时按 `Q`/`2` |
| 暂停 | `P` 或 `Esc` |
| 重开 | `R`（死亡后） |
| 静音 | `M` |
| 只开关背景音乐 | `B` |

### 手机端

- 左下角：虚拟摇杆，控制上下左右移动。
- 右下角：“攻击”按钮。
- 攻击按钮左侧：“换枪”按钮。
- 右上角：“暂停”、“音效”和“音乐”按钮。
- 在支持触屏的设备上，也可直接在画面右侧拖动来瞄准并攻击。

## 已修复 / 优化

- 背景建筑物现在绘制在丧尸与玩家之后，不会挡住战斗视野。
- 手机端按钮已放大，并在窄屏设备上自动显示。
- 适配触屏操作与移动端布局。
- 服务器支持局域网访问，并输出本机与局域网网址。

## 游戏内容

- 可上下左右自由移动的横板动作战斗
- 两类主战武器：
  - **球棍**：无限耐久、范围横扫、击退丧尸
  - **手枪**：远程点射、消耗子弹
- 丧尸类型：普通行者、高速爬行者、重甲壮汉
- 波次模式，每 5 波出现 **BOSS 暴君丧尸**
- 掉落物：医疗包恢复 HP，弹药盒补充子弹
- 血量、波次、分数、击杀数 HUD
- 动感程序化背景音乐：普通关卡、BOSS 波和死亡阶段有不同节奏与音色
- 屏幕震动、受伤反馈、粒子与简易合成音效

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面、HUD、菜单、结算界面与触屏按钮 |
| `style.css` | 响应式布局、桌面端与手机端 UI 样式 |

## 浏览器兼容

目标为现代浏览器（Chrome、Edge、Firefox、Safari 最新版本）。游戏使用 Canvas 2D、Pointer Events 和 Web Audio API，不需要安装任何前端依赖。服务器只需要 Node.js。
