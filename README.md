# 末日横板：枪械与棍棒打丧尸

一个纯前端、零依赖的 2D 横板网页小游戏。玩家在末日街区中上下左右自由走位，用 **球棍** 近身横扫，或切换 **手枪** 风筝尸潮。打破补给箱还能获得限时强化武器，并小心空中喷酸丧尸。

## 一键开始

### Windows
双击 `start.bat`，或执行：

```bash
npm start
```

### macOS / Linux
```bash
npm start
```

也可以直接运行：

```bash
node server.js
```

启动后服务器会打印入口网址，例如：

```
本机网址:   http://127.0.0.1:5173
局域网网址: http://192.168.x.x:5173
```

- 自己玩：打开 `http://127.0.0.1:5173`
- 局域网朋友玩：让手机/电脑与服务器连接同一 Wi-Fi，输入服务器打印的局域网网址。
- 自定义端口：

```bash
node server.js --port=8080
# 或
PORT=8080 node server.js
```

服务器还提供健康检查接口：

```
http://127.0.0.1:5173/healthz
```

## 让互联网上的玩家访问

本仓库本身是零依赖静态游戏，可以直接托管到任意静态平台。最简单的方式：

```bash
# 以 Vercel 为例，需要提前安装并登录 Vercel CLI
npx vercel --prod

# 或以 Netlify 为例
npx netlify deploy --prod --dir .
```

部署完成后会得到一个固定公网网址，其他玩家输入网址即可游玩。

如果不部署公网服务，也可以使用内网穿透工具，把本地 `http://127.0.0.1:5173` 映射到公网。

## 开始与主界面

1. 打开游戏后点击“开始游戏”。
2. 顶部会出现黄色加载进度条。
3. 加载完成后进入关卡主界面：
   - 左上角：头像、用户名、等级、钻石、金币
   - 中间区域：点击底部按钮会切换到对应功能界面
   - 头像可以打开玩家档案
   - 关卡界面可以用左右箭头切换当前关卡，右侧显示下一关锁定卡片
   - 点击“开始作战”进入当前关卡
   - 底部：商店、升级、关卡、背包、扩展关卡
   - 扩展关卡暂未开放，显示为灰色

## 通关结算

- 打完当前关卡最后一波的最终怪物后立即结算。
- 结算会按剩余血量显示通关百分比。
- 血量 100% 时显示《100%》完美通关和三颗星。
- 其他情况会显示对应百分比和对应星级。
- 可以选择再次挑战或返回主菜单。

玩家档案中可以：

- 更换内置头像或上传自定义头像
- 调节总音量、音效、音乐、震动

## 角色与技能

大厅「角色」页可选择幸存者，每个角色的一技能是大招（快捷键 **K**，手机点右下大按钮），二技能（快捷键 **L**，手机点小按钮）：

- **罗琳**（默认 · 双翼少女）：生命 100、攻防均衡。大招「融合解放」——5 秒内吸血 +10%、攻速 +20%、移速 +5%（冷却 30 秒），与二技能可叠加同时开启。特性：可在局外**复制其他角色的技能**，设为本关二技能。
- **丧尸撕裂者**（**对照官方设定图重绘**：白色蓬松爆炸乱发+低马尾、黑色口罩、发光红瞳、酒红长风衣+红领带+黑腰带、黑裤黑靴、血色双爪）：生命仅 60，但自带 **30% 吸血**与 **40% 减伤**。默认武器为**血爪**（近战双爪连斩）与**血刃**（隔空划出弧形血刃远程攻击）。大招「嗜血疾袭」——7 秒内移速 +100%、吸血 +15%、伤害 −50%、命中率 +70%（冷却 45 秒）。没有二技能槽。

技能激活期间角色脚下出现旋转光环、屏幕边缘亮起能量描边；技能冷却在按钮上显示倒计时，就绪时有呼吸光圈提示。

## 天赋系统

经验满升级时暂停并弹出三选一天赋（普通/稀有/史诗三档，共 11 种）。**同一天赋最多叠加 3 层**，层数越高收益越低（例如战意狂潮：+15% → +7% → +3%），鼓励搭配不同天赋；已选过的天赋在抽取池中权重降低但仍有概率再次出现。电脑按 1/2/3 快速选择。

## 角色形象定制

大厅「角色」页可自定义幸存者形象：7 套预设配色（默认/赤焰/翠林/紫影/金辉/冰蓝/墨夜）+ 色调/饱和度/亮度滑块，实时预览并立即在战斗中生效。配置持久化到本机，并提供**分享码**导入/导出——上传到抖音后，同一设备重新进入仍保留形象，换设备时用分享码即可转移。

### 手机端

- 屏幕上方中间：“暂停”按钮，已避开顶部积分栏。
- 首次进入战斗会显示操作提示，开火一次后自动消失。
- 已适配刘海屏安全区，画面按机型宽高比自适应，不再出现拉伸或黑边。
- 切到后台（如回复微信）时会自动暂停游戏。

## 游戏内容

- 可上下左右自由移动的横板动作战斗
- 武器系统：
  - **球棍**：默认近战，无限耐久、范围横扫、击退丧尸
  - **手枪**：默认远程武器，可拾取弹药补充
  - **冲锋枪**：高速连射，补给武器
  - **霰弹枪**：多发弹丸近距爆发
  - **步枪**：高伤害远程单发
  - **开山刀**：快速近战劈砍，有使用次数
- 丧尸类型（全部重绘为分类型矢量形象，从屏幕两侧走入战场，屏外来袭有红色箭头预警）：
  - **行者**：驼背前伸双臂的普通丧尸
  - **疾跑者**：四肢着地疾冲、背脊有骨突
  - **重甲壮汉**：肩甲铆钉、腹部缝线、拖着巨拳
  - **喷酸飞行者**：蝙蝠翼 + 发光酸囊，悬停风筝喷酸
  - **BOSS 暴君丧尸**：外露脑组织、金属颅板、胸腔心脏 + 肋骨、巨拳骨刺（BOSS 战血月 + 红色压迫滤镜）
  - **精英怪**：第 2 波起随机出现，红光环 + “精英”标记，血量 3.2 倍、伤害 1.5 倍、掉落 3 倍经验与补给
- **局内经验系统**：击杀掉落经验宝石（自动磁吸拾取），精英与 BOSS 大量掉落；HUD 左上角显示 LV 与经验条
- **局内天赋系统**：经验条满升级时暂停并弹出三选一天赋（普通/稀有/史诗三档，共 11 种：强健体魄、战意狂潮、迅捷步伐、经验磁石、嗜血、精准瞄准、荆棘装甲、巨人杀手、幸运搜刮、猎杀本能、死亡绽放），电脑可按 1/2/3 快速选择
- 地图补给箱：随机布置，可被武器或子弹破坏，破坏后随机掉落医疗包、弹药或强化武器
- 白天 / 夜晚地图：已拆分成单独关卡，不同关卡有不同敌人与补给配置
- 第一关为纯地面战，仅 3 波，适合先熟悉操作
- 掉落物：医疗包恢复 HP，弹药盒补充手枪子弹，强化武器为一次性补给
- 血量、经验、波次、分数、击杀数 HUD
- 动感程序化背景音乐：夜晚关卡、白天关卡、BOSS 波和死亡阶段有不同节奏与音色；可在暂停设置中自由调节音量
- 屏幕震动、受伤反馈、粒子与简易合成音效

## 装备养成与抽奖

大厅「升级」页为装备养成面板：左侧角色形象，右侧六项属性（生命值 / 攻击力 / 攻击速度 / 暴击率 / 暴击伤害 / 移动速度），下方为「装备 / 熔炼 / 突破」三个标签页。

- **六个槽位**（以图标展示）：头盔、胸甲 → 生命值；近战武器、远程武器 → 攻击力；裤腿、鞋子 → 攻击速度。每格小黑点代表升 1 级，默认 1 级无点，满级 70 级；槽位背景与边框颜色对应当前装备品质。
- **装备获取**：① 通关关卡有概率掉落，关卡越难掉率与品质越高；② 商店用抽奖券抽卡（×1 / ×10）。
- **抽奖券获取**：① 每关**首次**完美通关（3 星）送 1 张，重复通关只有金币；② 商店用钻石购买（25 钻/张，×10 225 钻）。
- **吸收升级**：点击背包中的装备即可吸收进对应槽位：白 +1 级、绿 +2、蓝 +3、紫 +4、金 +5、红 +7、彩虹 +9；吸收高于槽位品质的装备会提升槽位品质（加成系数更高）。
- **熔炼**：多余装备可熔炼为通用突破材料「强化结晶」+ 金币（白 +1 / 绿 +3 / 蓝 +6 / 紫 +12 / 金 +24 / 红 +48 / 彩虹 +100），支持一键熔炼白装。
- **突破**：每个槽位可突破 5 层，突破材料为强化结晶（白色品质装备仅需结晶，更高品质额外消耗金币）；每层提升全属性 —— 暴击率 +0.5%、暴击伤害 +5%、移动速度 +0.5%，直接作用于战斗（攻击有概率触发「暴击」飘字）。
- **品质**：白 → 绿 → 蓝 → 紫 → 金 → 红 → 彩虹。绿色需**通关第 10 关**解锁，其后蓝(18)、紫(26)、金(34)、红(42)、彩虹(50) 随通关进度相继解锁；未解锁前关卡不掉落、商店不产出对应品质。
- 关卡总数扩至 **60 关**（前 6 关为手工设计，之后程序生成、难度递增），支撑长线养成。

## 上线抖音小游戏路线图

本作目前是纯 H5（DOM + Canvas 2D）实现。抖音小游戏运行在字节跳动官方 runtime（`tt.*` API）中，没有 DOM，因此上线前需要一次“容器适配”改造，玩法代码（战斗、波次、武器、地图绘制）可以完整保留：

1. **注册与资质**：在抖音开放平台（developer.open-douyin.com）注册开发者账号；个人可发布试玩版，正式商业化（广告 / 内购）一般需要企业主体与游戏类目资质，软件著作权与版号要求以平台当期政策为准。
2. **容器适配层**：写一个 adapter，把以下 Web API 映射到 `tt.*`：
   - `document.createElement('canvas')` / `getContext` → `tt.createCanvas()`（主 canvas 由 runtime 注入）；
   - `localStorage` → `tt.getStorageSync` / `tt.setStorageSync`；
   - `Image` → `tt.createImage()`；
   - `AudioContext / Web Audio` → `tt.createInnerAudioContext`（音效改为音频文件）或平台支持的 WebAudio 兼容层；
   - `PointerEvent / 触控` → `tt.onTouchStart / onTouchMove / onTouchEnd`；
   - DOM 覆盖层 UI（菜单 / HUD / 大厅）→ 改为 Canvas 绘制或接入 Cocos / Laya 的 UI 系统。
3. **推荐做法**：若计划长期迭代，建议用 Cocos Creator / LayaAir 重建工程并导入现有玩法逻辑；若想最快上线，可保留本引擎并手写薄 adapter（游戏本体为零依赖单文件，改造成本低）。
4. **包体与目录**：按平台要求组织 `game.json`、`game.js` 与资源目录，注意主包体积限制（超限的资源放远程 CDN）。
5. **抖音生态接入**（上线后）：激励视频复活 / 双倍奖励（`tt.createRewardedVideoAd`）、插屏广告、抖音授权登录与好友排行（`tt.getFriendsCloudStorage`）、录制分享短视频引流。
6. **横屏**：在 `game.json` 中声明 `deviceOrientation: "landscape"`，与现有横板玩法一致。

完成容器适配后，本仓库的 `game.js` 玩法层（视口自适应、触控双区操作、性能预烘焙）可直接迁移。
