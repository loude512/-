# 末日横板：枪械与棍棒打丧尸

一个纯前端、零依赖的 2D 横板网页小游戏。玩家在末日街区中上下左右自由走位，用 **球棍** 近身横扫，或切换 **手枪** 风筝尸潮。打破补给箱还能获得限时强化武器，并小心空中喷酸丧尸。

## 一键开始

### Windows
双击 `start.bat`，或执行：

```bash
npm start
```

### macOS / Linux
```bash
npm start
```

也可以直接运行：

```bash
node server.js
```

启动后服务器会打印入口网址，例如：

```
本机网址:   http://127.0.0.1:5173
局域网网址: http://192.168.x.x:5173
```

- 自己玩：打开 `http://127.0.0.1:5173`
- 局域网朋友玩：让手机/电脑与服务器连接同一 Wi-Fi，输入服务器打印的局域网网址。
- 自定义端口：

```bash
node server.js --port=8080
# 或
PORT=8080 node server.js
```

服务器还提供健康检查接口：

```
http://127.0.0.1:5173/healthz
```

## 让互联网上的玩家访问

本仓库本身是零依赖静态游戏，可以直接托管到任意静态平台。最简单的方式：

```bash
# 以 Vercel 为例，需要提前安装并登录 Vercel CLI
npx vercel --prod

# 或以 Netlify 为例
npx netlify deploy --prod --dir .
```

部署完成后会得到一个固定公网网址，其他玩家输入网址即可游玩。

如果不部署公网服务，也可以使用内网穿透工具，把本地 `http://127.0.0.1:5173` 映射到公网。

## 操作说明

### 电脑端

| 操作 | 按键 |
| --- | --- |
| 上 / 下 / 左 / 右移动 | `W` `A` `S` `D` 或方向键 |
| 攻击（瞄准 / 挥棍 / 射击） | 鼠标左键、`J`、`空格` |
| 切换武器 | `Q`、页面“切换武器”按钮 |
| 直接选择已拥有武器 | `1`～`6`，对应物品栏位置 |
| 子弹耗尽 | 自动切换球棍；拾取弹药后自动切回手枪 |
| 暂停 / 设置 | `P` 或 `Esc` |
| 重开 | `R`（死亡后） |
| 静音 | `M` |
| 只开关背景音乐 | `B` |

### 手机端

- 左下角：固定虚拟摇杆，控制上下左右移动。
- 第一个落在左侧的触点用于移动；之后另一个触点可以在任意位置点按/拖动，用于瞄准并攻击。
- 因此可以一只手控制摇杆移动，另一只手同时在屏幕任意方向瞄准攻击，包括攻击左侧的丧尸。
- 右下角：“换枪”按钮。
- 屏幕上方中间：“暂停”、“音乐”和“音效”按钮，已避开顶部积分栏。

## 暂停设置

暂停后可以：

- 调节主音量、音乐、音效
- 单独开关背景音乐与音效
- `重置设置`
- `继续游戏`
- `返回主界面`
- `退出游戏`（浏览器允许时关闭页面，否则返回标题）

- 手机端按钮已放大，并在窄屏设备上自动显示。

## 游戏内容

- 可上下左右自由移动的横板动作战斗
- 武器系统：
  - **球棍**：默认近战，无限耐久、范围横扫、击退丧尸
  - **手枪**：默认远程武器，可拾取弹药补充
  - **冲锋枪**：高速连射，补给武器
  - **霰弹枪**：多发弹丸近距爆发
  - **步枪**：高伤害远程单发
  - **开山刀**：快速近战劈砍，有使用次数
- 丧尸类型：普通行者、高速爬行者、重甲壮汉、空中喷酸丧尸、每 5 波出现的 **BOSS 暴君丧尸**
- 地图补给箱：随机布置，可被武器或子弹破坏，破坏后随机掉落医疗包、弹药或强化武器
- 白天 / 夜晚地图：波次推进会切换场景、配色和音乐氛围
- 掉落物：医疗包恢复 HP，弹药盒补充手枪子弹，强化武器为一次性补给
- 血量、波次、分数、击杀数 HUD
- 动感程序化背景音乐：夜晚关卡、白天关卡、BOSS 波和死亡阶段有不同节奏与音色；可在暂停设置中自由调节音量
- 屏幕震动、受伤反馈、粒子与简易合成音效

## 浏览器兼容

目标为现代浏览器（Chrome、Edge、Firefox、Safari 最新版本）。游戏使用 Canvas 2D、Pointer Events 和 Web Audio API，不需要安装任何前端依赖。服务器只需要 Node.js。
